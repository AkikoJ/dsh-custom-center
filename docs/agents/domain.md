# Domain Docs

本仓库采用 single-context 布局：

- 根目录 `GLOSSARY.md`：共享领域词汇。
- `docs/adr/`：架构决策记录。

## 探索前读取

探索代码前，读取 `GLOSSARY.md`，以及涉及当前工作范围的 ADR。

如果这些文件不存在，静默继续。由 domain-modeling 技能在术语或决策
实际明确时按需创建。

## 使用领域词汇

任务标题、设计建议、假设和测试名称中的领域概念，使用词汇表定义的名称，
遵守其中的 Avoid 约定。

遇到词汇表未收录的概念，先确认是否符合项目用语；
确有缺口时，记录为 domain-modeling 的后续输入。

## 标明决策冲突

如果建议与已有 ADR 冲突，明确标出 ADR 编号、冲突点和重新讨论的理由。
