# 抖音登录交付与验收

当前交付范围为 macOS 本机单账号登录，采用 Node.js、Playwright 1.64.1 及其匹配的 Chromium。登录归属遵循 ADR-0003。本文区分自动化检查与实际运行证据；未完成的项目不能视为已交付。

锁文件中的 Playwright 浏览器清单指定 Chromium `156.0.8078.4`、revision `1248`。该信息来自已安装 npm 包的清单读取，不代表已下载或实际启动该二进制。

## 浏览器准备

在本插件安装目录使用锁定依赖，运行以下明确安装命令；这是用户主动执行的浏览器准备步骤，不由设置页触发：

```sh
pnpm run douyin:install-browser
```

第三方资源统一使用 `$DSH_HOME/vendor/`（默认 `~/.dsh/vendor/`），每个工具使用独立子目录。浏览器资源位于其中的 `playwright/`，即默认 `~/.dsh/vendor/playwright/`。Chromium、Headless Shell 和 FFmpeg 共享此目录，可跨插件、跨 profile 复用匹配版本；账号数据仍按 profile 隔离，不进入 vendor。此约定适用于本插件管理的外部资源，npm 包仍由各自包管理器及锁文件管理。安装脚本与宿主使用同一规则；显式设置的 `PLAYWRIGHT_BROWSERS_PATH` 优先（包括 Playwright 的 `0` 本地安装模式）。准备浏览器及运行 DSH 必须使用相同用户和配置，修改后完整重启 DSH，因为 Playwright 在首次导入时确定目录。插件不回退到系统 Chrome。升级 Playwright 后需要重新准备匹配的 Chromium。

旧版本已下载至 `~/Library/Caches/ms-playwright/` 的资源，可以将当前版本对应的 `chromium-1248`、`chromium_headless_shell-1248` 和 `ffmpeg-1013` 文件夹复制到新目录，保留其他工具使用的旧缓存。也可重新运行上述安装命令。安装位置可用 `pnpm run douyin:install-browser --print-path` 查看。

Playwright 保持宿主外部运行依赖，不能仅复制宿主 JS 文件而遗漏包依赖、playwright-core 或浏览器资源。正式插件安装仍按仓库的 DSH 安装流程执行，安装不等同于源码校验。构建及安装到正在运行的 profile 须遵循用户单独授权，本次不自动执行。

## 使用与状态

1. 在设置中打开「抖音账号」。首次进入只读取状态，不启动窗口或下载浏览器。
2. 点击「打开登录窗口」，在真实抖音网页扫码或完成手机确认、短信或验证码。
3. 等待自动观察，也可点击「检查登录状态」。账号必须由平台成功响应及 UID 确认；昵称只用于展示。
4. 浏览器已确认且凭据保存成功即完成登录。独立 Node HTTP 返回同 UID 才显示「HTTP 已验证」，临时失败显示「HTTP 待验证」，保留网页登录。
5. 关闭登录窗口会保留浏览器会话。重启宿主后上次保存摘要只作历史资料，重新开窗检查才确认当前有效性。

自动轻量观察约 3 秒，身份检查至少间隔 10 秒并对临时失败退避，单次网络超时约 15 秒；等待约 10 分钟暂停自动观察，窗口与步骤保留，可手动继续。设置页卸载只取消页面请求，不退出抖音。

快照及专用 browser profile 位于 `$DSH_PROFILE_DIR/custom-center/douyin/`；无 profile 时回退至 `$DSH_HOME/custom-center/douyin/`，再回退至 `~/.dsh/custom-center/douyin/`。目录和文件仅当前系统用户可访问，不应加入版本控制或备份分享。页面不提供下载、复制或凭据接口。

浏览器 Cookie 源与 HTTP CookieJar 同处版本化快照但独立维护：重新打开窗口只恢复浏览器源，HTTP 更新不反向注入窗口。分区 Cookie 原样保存，不作为普通 Cookie 发送；HTTP 收到不支持的分区更新时保持待验证，不扩大其作用范围。

## 故障处理

| 页面反馈 | 恢复方式 |
| --- | --- |
| 缺少 Chromium | 使用相同版本、系统用户及缓存配置执行浏览器准备命令 |
| profile 占用 | 关闭所属旧登录窗口或等待插件释放；不要删除锁文件或强行结束其他浏览器 |
| 页面加载失败 | 检查网络后重新打开；此结果不表示已完成登录 |
| HTTP 待验证 | 查看脱敏原因；限流时等待，挑战时在浏览器继续，再手动检查 |
| 账号不一致 | 相关凭据停用；本期不支持切换，不会覆盖已绑定 UID |
| 保存失败 | 检查宿主数据目录权限与磁盘空间；上一份完整资料保留，本次不算保存成功 |
| 历史资料不可用 | 不消费损坏或未知版本快照；重新开窗完成可信身份验证后再保存 |

当前账号候选为固定的 `profile/self` 只读接口，要求业务成功且 UID 非空。真实平台可能对签名、挑战或请求环境提出新要求；不得把历史实现的“无需签名”注释当成保证。如果真实同 UID HTTP 验证受阻，应记录证据并单独评估，不扩展为私信协议逆向。
