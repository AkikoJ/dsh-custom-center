# 抖音登录由中心独立持有会话，Cookie 仅在宿主内部派生

用户确认在 `dsh-custom-center` 新增抖音账号功能，采用 Node.js + Playwright 配套 Chromium，让用户在真实网页完成登录；两个旧插件只作参考，不依赖它们的 Python/MCP 或浏览器进程。
本项目自行持有持久浏览器会话和内部 Cookie 快照，Cookie 不提供下载或前端明文接口；浏览器登录与独立 HTTP 可用性分别验证和展示，HTTP 临时失败不直接撤销浏览器登录。

继续复用旧 Python/MCP 能减少部分登录流程迁移，但会引入第二运行时和跨插件生命周期耦合；直接复制 scroll 的 CDP 脚本更轻，却需要自行维护协议封装、身份验证、平台控制和 Cookie 匹配。选择 Playwright 接受浏览器资源部署与版本维护成本，以换取在当前 TypeScript 插件内完整拥有会话生命周期。

使用配套 Chromium 而非本机 Chrome 是用户的明确选择，因此浏览器准备必须成为可验证的交付环节。此记录接受边界和技术方向，不表示已安装依赖、验证运行环境或实施功能。

一期限定 macOS 本机单账号，关窗保留会话，不提供切换或清除登录。详细流程、接口、异常语义和验收见 [实施计划](../douyin-login-plan.md)。
