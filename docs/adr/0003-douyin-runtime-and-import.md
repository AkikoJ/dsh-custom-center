# 0003 抖音运行路径与离线导入

状态：Accepted

## 背景

抖音插件宿主、Python MCP、视频理解命令和 headless 必须共享浏览器登录态与账本。源实现部分路径忽略 DSH_HOME，部分从脚本目录推导；直接移动代码会产生两套状态。旧用户还可能自行修改脚本与提示词。

## 决策

功能归 src/douyin，Python 和提示词归 resources/douyin。入口只装配，业务通过明确的配置、存储、执行、进程和平台依赖协作。界面、工具和定时任务共用操作实现。

数据根按 DSH_CUSTOM_CENTER_DOUYIN_HOME、DSH_HOME/dsh-custom-center/douyin、~/.dsh/dsh-custom-center/douyin 顺序解析。宿主不读取旧插件的 DSH_DOUYIN_HOME；只在自己启动的子进程中将它设置为中心版目录以兼容脚本协议。持久状态分类存储，cache 可清理，browser 不作为临时缓存。路径解析不依赖 cwd 或包安装目录。所有子进程显式注入路径，不修改宿主环境。

旧目录导入由独立命令完成，启动插件不自动导入。导入复制并保留源，先验证占用状态与内容，再以不覆盖方式复制，清单持久化支持中断续传，最后写完成标记。仅改写应用自有旧路径，用户自定义路径原样保留。Python 环境不直接迁移，必须验证可用或重建。

包版本与上游版本分开，更新检查从独立来源元数据读取。源码中使用 import.meta.url 定位随包发布的资源，并在临时安装目录验证。

## 影响

默认新目录独立于旧插件，注册名称、工具、路由与浏览器用户目录也独立，允许同时加载。导入时需先停止来源后台任务以获得一致快照；导入后可独立启用，两套账号额度与去重账本不合并。开发仅使用临时目录与业务替身，不能以真实账号写操作作为测试。
