# 02: 外观功能完整迁移

**What to build:** 将外观从页面、预览与本地存储到壁纸库接口的完整实现集中到外观功能，使维护者能够按功能追踪实现，用户继续获得相同的显示、操作和保存结果。

**Blocked by:** 01 — 共享边界整理与行为基线。

**Status:** resolved

**Type:** task

## 实施范围

依据父规格《按三个功能组织个性化中心源码》、定稿方案的完整迁移映射及 ADR-0002，整体迁移外观的浏览器实现、宿主接口和纯逻辑。
本任务不依赖上下文与压缩迁移；修改共用装配入口时保留其他任务已完成的引用变更。

- [x] 外观页面、壁纸库选择、控制器、壁纸存储、请求、配色、皮肤、取色、色调、媒体规则及宿主素材接口均有唯一的功能归属。
- [x] 浏览器与宿主实现在功能内部区分，纯逻辑直接归功能；保留模块及声明名称，不新增聚合导出、空壳兼容文件、状态容器或额外纯逻辑层级。
- [x] 同步更新两个真实装配入口、全部现有消费者及相关测试导入，既有测试保留原组织与断言意图。
- [x] 草稿、预览、退出恢复、已保存设置、图片与视频壁纸、配色、遮罩、输入框不透明度及正文加强的现有实现保持一致。
- [x] 保留本地存储键、IndexedDB 结构、素材目录、环境变量求值时机、异步状态更新及现有错误反馈，不迁移用户数据或修复既有行为。
- [x] 壁纸库接口路径、方法、请求头、响应字段、状态码、错误和守卫顺序保持一致；上传、重名、类型与签名、列表、Range、大小限制、路径逃逸及符号链接行为保持一致。
- [x] 两个共享请求声明直接引用共享边界；外观和上下文与压缩互不导入，共享边界无反向依赖，浏览器运行时不达 Node 或服务端实现，无运行时依赖环。
- [x] 通过无产物类型检查及颜色、皮肤、取色、媒体、壁纸库相关回归；优先沿用请求、响应和临时素材目录结果等现有高层接缝，只补确实缺失且可能受影响的行为覆盖。
- [x] 对照本轮基线，运行声明只允许必要引用和既定共享声明归属变化，CSS、组件结构、挂载边界、控制器创建及清理顺序保持一致；Skills 无无关改动。
- [x] 差异空白检查通过，所有受影响手写文件不超过 800 物理行；更新本轮验证记录，区分自动检查与尚待真实宿主验证的效果。
- [x] 保留用户已有改动；不修改 DSH 宿主源码、依赖、锁文件、入口配置或已有产物，不自动构建、提交或推送。

## Answer

完整迁移外观纯逻辑、浏览器和宿主模块；所有消费者与测试直接引用新路径。无产物类型检查通过；外观回归 5 文件 / 57 测试通过。声明与导入绑定等价、CSS 摘要及既有产物一致，依赖边界与差异空白检查通过。真实宿主效果仍待验收，详见[本轮验证记录](../../../docs/feature-organization-validation.md)。
