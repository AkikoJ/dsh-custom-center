# 03: 上下文与压缩功能完整迁移

**What to build:** 将上下文与压缩从页面操作、参数计算到宿主配置写入的完整实现集中到同一功能，使维护者能够按功能追踪配置结果，用户继续获得相同的应用范围、压缩策略与操作反馈。

**Blocked by:** 01 — 共享边界整理与行为基线。

**Status:** ready-for-agent

**Type:** task

## 实施范围

依据父规格《按三个功能组织个性化中心源码》、定稿方案的完整迁移映射及 ADR-0002，整体迁移上下文与压缩的浏览器实现、宿主接口和纯逻辑。
本任务不依赖外观迁移；修改共用装配入口时保留其他任务已完成的引用变更。

- [ ] 页面、面板、专用选择控件、请求、模型窗口与压缩计算、宿主配置接口均有唯一的功能归属；专用选择控件留在本功能内。
- [ ] 浏览器与宿主实现在功能内部区分，纯逻辑直接归功能；保留模块名、声明名、页面与面板的嵌套和挂载边界，不新增聚合导出、空壳兼容模块或额外状态容器。
- [ ] 同步更新两个真实装配入口、全部现有消费者及相关测试导入，既有测试保留原组织与断言意图。
- [ ] 当前模型和 Agent 预设的读取、模型窗口与输出预留容量的校验和显示保持一致；应用范围继续覆盖既有单模型、供应商与全部可编辑模型语义。
- [ ] Agent 预设的自动压缩设置、参数拒绝、未知目标、顺序写入、请求失败及中途失败可能部分生效的现有行为保持一致，不夹带事务化或错误提示修复。
- [ ] 宿主接口路径、方法、请求头、响应字段、状态码、错误、守卫顺序和按请求解析服务的时机保持一致，不统一原有请求实现或守卫差异。
- [ ] 两个共享请求声明直接引用共享边界；上下文与压缩和外观互不导入，共享边界无反向依赖，浏览器运行时不达 Node 或服务端实现，无运行时依赖环。
- [ ] 通过无产物类型检查及上下文与压缩计算、宿主调优接口相关回归；沿用路由输入、响应及宿主配置结果等现有高层接缝，只补确实缺失且可能受影响的行为覆盖。
- [ ] 对照本轮基线，保留 DOM、属性、受控输入、事件、计时器、焦点与 Escape 处理、样式及生命周期；Skills 无无关改动，不新增功能子插件。
- [ ] 差异空白检查通过，所有受影响手写文件不超过 800 物理行；更新本轮验证记录，区分自动检查与尚待真实宿主验证的效果。
- [ ] 保留用户已有改动；不修改 DSH 宿主源码、依赖、锁文件、入口配置或已有产物，不自动构建、提交或推送。
