# 03: 处理凭据失效与 HTTP 异常

Type: task
Status: resolved
Blocked by: 01

**What to build:** 已登录用户遇到网络失败、限流、挑战页或认证拒绝时，可以从页面判断应等待、重试还是查看浏览器；明确失效或账号不一致时宿主停止使用凭据，临时 HTTP 故障则保留登录及完整资料。

依据父规格《抖音账号登录与宿主内部凭据》及 ADR-0003，扩展任务 01 已具备的基本凭据边界。任务不依赖自动观察，也不扩展成通用平台 API 或私信协议实现。

- [x] 将 HTTP 网络错误、超时、限流、挑战响应、认证拒绝及 UID 不一致映射为可理解的状态和重试建议，不把所有失败统一标为退出登录。
- [x] 临时 HTTP 失败保留已确认的浏览器认证和完整快照，页面显示「HTTP 待验证」及脱敏原因；手动检查可恢复同 UID 验证。
- [x] 平台明确未登录时使凭据过期并停止内部消费；HTTP 身份不一致时拒绝该凭据代次，不覆盖当前账号，不静默切换到新 UID。
- [x] 在尚无可信身份结论时保持待确认，HTTP 状态码成功或存在 Cookie 不能替代业务成功及 UID 校验。
- [x] HTTP 结果绑定 UID、凭据代次及时间；Cookie 更新产生新代次并使旧结论失效。旧请求即使稍后成功也不能为新代次提供有效结论。
- [x] HTTP 更新 Cookie 后按快照规则保存完整新代次，不实现浏览器与 HTTP 的通用双向同步，不盲目复制全部浏览器请求头，也不承诺 Cookie 与 User-Agent 足以访问所有接口。
- [x] 基于真实 CookieJar 和受控出站网络验证精确域边界、host-only 与子域、路径、重名、过期、Secure、会话 Cookie 及分区属性处理；无关目标不能收到账号 Cookie。
- [x] 重定向逐跳检查允许域及协议，重新计算目标 Cookie；未知域拒绝携带凭据，不因重定向或相似域名越过边界。
- [x] 从宿主路由入口覆盖临时失败保留登录、显式失效停止消费、UID 不一致、Cookie 更新后旧验证失效、延迟响应乱序及重试恢复；测试传输仅在测试组合中替换，生产入口不增加任意 URL 后门。
- [x] 页面及错误信息不暴露 Cookie、Token 或完整平台响应，诊断记录只含可追踪的阶段、脱敏原因及验证时间；未来内部调用只能消费满足账号及有效性规则的凭据。
